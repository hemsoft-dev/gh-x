# Perfection history, 2026-11-05

## 18:35 - Make the mutation gate test real mutants

[Issue #264](https://github.com/hemsoft-dev/gh-x/issues/264): Gremlins v0.6.0 tested the module root for
`package main` under `src`, so every covered mutant was a setup failure counted as killed. V1.4 routes local
and CI mutation runs through the shared gate and its `go` shim, which runs the real `./src` tests per mutant
and rejects unproven runs. The first full real run took 62 minutes on 12 CPUs and scored 81.00% efficacy
(2,067 killed, 485 lived) and 93.69% mutator coverage, below the 90% efficacy floor. Retrospective: two
earlier full runs were invalid. Mini's quota-limited `/tmp` broke mutation restores, and one worker per CPU
caused false timeouts. Always check a run for apply/restore errors and deadline-clipped durations before
trusting its score.

## 23:04 - Qualify the corrected mutation candidate

Strengthened 12 source test files and rejected resource-only or unexplained package failures in the shim. The
full candidate passed with 2,456 killed, 114 lived, 241 not viable, 11 timed out and 152 uncovered: 95.56%
efficacy, 94.42% mutator coverage and zero unproven runs. It took 74 minutes with 3 workers; hosted CI remains
the delivery gate. Linux race tests include a real SIGKILL negative control. Windows executor regressions
pass; the bounded allocation controls are Linux-only. Retrospective: preserve panic or named-test evidence for
every kill and keep rejected OOM-ambiguous runs separate from accepted measurements.
